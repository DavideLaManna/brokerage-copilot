## 2026-01-26 - US-011: Risk engine - pre-trade validation (COMPLETED)

### What was done:
- Created src/services/risk-engine.ts with RiskEngine class for pre-trade validation
  - validateOrder(order, context) function validates orders against risk configuration
  - Returns OrderValidationResult with pass/fail status, individual check results, and rejection reasons
- Implemented 7 risk checks:
  1. **risk_per_trade**: Blocks if order max loss exceeds maxRiskPerTradePercent of account value
  2. **concentration**: Blocks if total exposure to underlying exceeds maxRiskPerUnderlyingPercent
  3. **buying_power**: Blocks if estimated order cost exceeds available buying power
  4. **dte_range**: Blocks options with DTE outside minDTE/maxDTE range
  5. **liquidity**: Blocks if bid-ask spread exceeds configurable threshold (default 5%)
  6. **max_positions**: Blocks if position count would exceed maxOpenPositions limit
  7. **max_contracts**: Blocks if contract count per position would exceed maxContractsPerPosition
- Each check returns detailed RiskCheckResult with:
  - checkType identifier
  - passed boolean
  - Human-readable message explaining result
  - details object with actual value, limit, and unit
- Comprehensive logging for audit trail:
  - All validation attempts logged with timestamp, order details, pass/fail counts
  - Failed validations include rejection reasons
  - Configurable logger interface for integration with external logging systems
- Factory function createRiskEngine() and standalone validateOrder() convenience function
- Updated src/services/index.ts with RiskEngine exports
- Added 37 comprehensive tests in src/services/risk-engine.test.ts covering:
  - All 7 risk check types (pass and fail scenarios)
  - Edge cases (zero account value, missing quotes, equity orders)
  - Multiple simultaneous failures
  - Custom configuration (liquidity threshold)
  - Logging verification

## 2026-01-26 - US-013: Portfolio exposure calculator (COMPLETED)

### What was done:
- Created src/services/exposure-calculator.ts with ExposureCalculator class
  - Aggregates positions by underlying symbol (options grouped by underlying, equity by symbol)
  - Calculates notional exposure: contracts * strike * multiplier for options, qty * price for equity
  - Calculates risk (max loss) per underlying:
    - Long options: premium paid (market value)
    - Short puts: strike * multiplier * contracts
    - Short calls: 3x strike (unlimited proxy)
    - Long equity: market value
    - Short equity: 2x market value (unlimited proxy)
  - Computes exposure and risk as percentage of account value
  - Flags underlyings exceeding concentration limit (uses maxRiskPerUnderlyingPercent from RiskConfig)
  - Aggregates Greeks (delta, gamma, theta, vega) across option positions per underlying
  - Calculates net quantity (delta-equivalent shares for options)
  - Includes position-level breakdown with DTE for options
  - Sorts underlyings by exposure percentage (descending)
- Created src/ui/components/ExposurePanel.tsx
  - Displays "Exposure by Underlying" panel on dashboard
  - Summary stats: Total Notional, Total Risk, Risk % of Account, Concentration Limit
